# ProofLab

ProofLab is an interactive workshop for learning mathematical proof. Explore definitions and worked examples, practise with logic activities, and get guided feedback while building a proof.

## Run locally

Requires Node.js 20.19 or newer.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Notes

Progress, activity points, and theme preference are stored in this browser with local storage. The proof checker provides educational, rule-based guidance; it is not a formal proof verifier and cannot establish the validity of arbitrary mathematical arguments.
